### 为什么是这块板（而不是便宜的 ESP32-S3 裸板）

这块板**已经把下面这些全部做在上面了**，你一个零件都不用自己接：

- 摄像头（顺带的，本用项目用不上）
- 姿态传感器（以后做自平衡能用上）
- 外壳，不带螺丝，手就能拆开

如果要省钱买裸板自己搭，你要额外买麦克风模块、功放模块、喇叭、屏幕，然后接二三十根线。**对零基础来说，这省下的几十块钱不值得。**

### 买回来干什么：10 分钟变成 AI 音箱

**完全不用装任何开发环境。** 小智支持网页在线烧录：

1. 用 Chrome 或 Edge 打开 **https://www.16302.com/xiaozhiinit**
   （备选：乐鑫官方 https://espressif.github.io/esp-launchpad/）
2. Type-C 线连电脑和板子
3. 网页上点「连接设备」，选择你的 COM 口
4. 厂商列表里选 **立创 / LCKFB / 实战派 ESP32-S3** 对应的固件
5. 点烧录，等进度条走完
6. 拔下来重新上电 → 板子会开一个 Wi-Fi 热点 → 手机连上 → 选你家的 Wi-Fi → 扫码绑定
7. 喊一声唤醒词，开始聊天

> 官方图文教程：https://xiaozhi.me/xz-docs/docs/tutorial-basics/flash-tool-or-web-firmware-burning/

### 选购要点（这里踩坑的人最多）

**1. 舵机必须买「180 度」版本，绝对不能买 360 度的！**

这是**新手第一号坑**。舵机在商品页通常有两个选项：
- `180°` —— 可以控制**角度**（转到 90 度停住）→ ✅ **要这个**
- `360° 连续旋转` —— 只能控制**转速和方向**，完全无法定位 → ❌ 买了就废

机器人只能用 180 度版。**下单前一定看清型号和选项。**

**2. 一定要金属齿（MG90S），别图便宜买塑料齿 SG90**

只差几块钱，但塑料齿在持续撑地的场景里很快就扫齿报废。八爪鱼要一直用触手撑着自己。

**3. 舵机不能用 USB 或充电宝供电**

- 电脑 USB 口：最大 0.5~0.9A，舵机一动就触发过流保护
- 充电宝：多数单口限流 2A，而且小电流时会**自动休眠断电**
- **必须买独立的 5V 6A（或更大）开关电源适配器**

**4. 杜邦线买套装**

一套里同时包含「公对公、公对母、母对母」三种，反正就几块钱。买单一规格的话，一旦发现接口是公是母猜错了，还得再等一次快递。

### 接线：一共只需要动手 4 处

先看清楚立创实战派板上有**两个白色的 GH1.25 小插座**，其中一个是标 **I2C** 的扩展口（和板上触摸屏、音频芯片共用这条 I2C 总线，板上 males。

> 这条总线的引脚已经在小智固件里写死了：**SDA = GPIO 1，SCL = GPIO 2**。不用担心候。

**动作 1** —— 开发板自带的「GH1.25-5P 转杜邦线」，GH1.25 那头插到板子的 **I2C 扩展口**。

**动作 2** —— 转接线另一端的杜邦线，挑 3 根接到 PCA9685：

| 开发板扩展口 | PCA9685 |
|---|---|
| SDA | SDA |
| SCL | SCL |
| GND | GND |

**动作 3** —— 接外部电源（这是唯一需要拧螺丝的地方）：
- 把 5V 电源适配器的 DC 头插进「DC 母头转接线」
- 母头线会出来两根裸线，**红线（正极）拧进 PCA9685 上标 V+ 的端子，黑线（负极）拧进 GND 端子**
- 用螺丝刀拧紧即可

**动作 4** —— 4 个舵机的三针插头，直接**插到 PCA9685 上的排针**（排针是 3 根一排，共 16 排）。
方向看排针旁边的丝印：一般是 `GND / V+ / PWM`（或 `- / + / S`），对应舵机的 **棕/黑 → GND，红 → V+，黄/橙 → 信号**。

**就这些。没有焊接，没有剪线，全程可逆。**

### ⚠️ 唯一必须记住的一条：必须共地

PCA9685 的 GND **必须**和开发板的 GND 连在一起（就是上面动作 2 的那根 GND 线）。

不共地的表现是：舵机完全不动，或者疯狂抽搐。**这是新手第二号故障，几乎所有人都会漏一次。**

### 先在 Arduino 里验证，跳过 ESP-IDF 的痛苦

在正式编译小智固件之前，强烈建议先用 **Arduino IDE** 跑通：

1. 装 Arduino IDE，添加 ESP32 板支持（开发板管理器搜 `esp32`）
2. 库管理器搜 **`Adafruit PWM Servo Driver`** 并安装
3. 打开 `文件 → 示例 → Adafruit PWM Servo Driver → servo`
4. 接线完全一样，改一下 `Wire.begin(1, 2)` 里的引脚号
5. 上传，看舵机有没有转到中位

**为什么这么做**：Arduino 编译快、报错人能看懂。ESP-IDF 环境搭建对新手是相当劝退的一步。**先在 Arduino 里确认硬件没毛病，再去搞 ESP-IDF**，免得到时候分不清是接线错了还是环境错了。

测完把小智固件用网页重新刷回去就行，一分钟的事。

> Arduino IDE 里记得把开发板选成 `ESP32S3 Dev Module`，并把 `USB CDC On Boot` 设为 Enabled，否则串口看不到输出。

### 无线版接线要点（和有线版的区别）

- 电池 7.4V → XL4015 → **6V** 接 PCA9685 的 V+ 端子（不是 5V，扭矩更高）
- XL4015 同时取 **5V** 接 ESP32 的 VIN/5V 引脚
- **三者共地**：电池 GND、ESP32 GND、PCA9685 GND 全部连通
- ESP32 只和 PCA9685 走 I2C（SDA/SCL/GND 三根），不再接麦克风/喇叭/屏幕
- 蓝牙用 ESP32 自带 BLE，无需额外模块

| 现象 | 几乎一定是这个原因 |
|---|---|
| 板子完全没反应，屏幕不亮 | Type-C 线是纯充电线，不传数据；换个确认能传数据的线 |
| 浏览器选不到 COM 口 | 没装 CH340/CH343 驱动 |
| 舵机完全不动 | **没有共地**；或外部电源没接；或 PWM 频率不是 50Hz |
| 舵机抖动、抽搐 | **没有共地**；或者不小心买了 360° 舵机 |
| 舵机一转板子就重启 | 舵机从 ESP32 取电了 —— 必须走 PCA9685 的 V+ 端子 |
| 只有部分通道有反应 | I2C 地址冲突；或第二块板的地址跳线没短接 |
| 舵机到位后一直"咯咯"响 | 角度超出机械极限，需要软件限位（`SetTrim` / `SetLimit`） |
| 能转，但八个不同步 | 步态参数问题，不是硬件问题 —— 去调 `GaitParams` |

## 关于 ESP32-S3 的一个硬限制（要记住）

ESP32-S3 有 8 个 LEDC 硬件通道，所以**最多 8 路舵机能直连 GPIO**。小智官方的 `otto-robot` 用 6 路（4 条腿 + 2 只手），刚好够，所以它那样跑没问题。

**但方案 B 需要 16 路，直接超过硬件上限**——这就是必须用 PCA9685 的根本原因，不是因为"驱动能力不行"。

好消息是：一旦用了 PCA9685，将来要扩到 24 路甚至 48 路，只要往同一条 I2C 总线上再挂几块板就行，**接线一根都不用改**。

## 成品大概多大、多重

方案 B 的尺寸**不是随便定的，是被两个硬东西卡住的**：

- **躯干直径的下限 = 主控板**：立创实战派 S3 是 69×41mm，对角线就有 80mm。躯干做不进这个矩形，板子就装不进去。所以躯干直径至少 90mm，留点余量取 **100mm**。
- **舵机档位决定了上限**：MG90S 扭矩 1.8 kg·cm（5V）。触手越长力矩需求线性增长，超过 10cm 就没余量了。

| 项目 | 数值 |
|---|---|
| 躯干直径 | 约 10 cm |
| 触手长度 | 约 9 cm（建议 7~9 cm，别更长） |
| **展开直径** | **约 27 cm** |
| 站立高度 | 约 6~7 cm |
| 整体重量 | 约 0.5 kg |

参照物：摊开后比 A4 纸的短边（21cm）还宽一点，差不多一个中等圆盘 / 小南瓜；收起触手时直径约 15cm。

### 重量构成与力矩校验（这一段别跳过）

| 部件 | 重量 |
|---|---|
| MG90S ×16 | 214 g |
| 立创实战派 S3 板 | 60 g |
| PCA9685 模块 | 15 g |
| PLA 结构件 | 150~250 g |
| 线材端子 | 20 g |
| **合计** | **约 510 g** |

**能不能撑得住？** 支撑时通常只有 8 条触手着地，每条触手靠俯仰舵机承重（偏航那个不承重）。触手在约 6cm 处触地：

- 理论峰值：1.8 kg·cm ÷ 6cm = 300g/舵机 × 8 = 2400g
- 但标称值多为堵转值，**持续输出只能按 1/3 ~ 1/2 算** → 实际约 1000g
- 爬行推进时有 2~3 倍冲击载荷 → 需要约 1000~1500g

**结论：能撑住，但余量只有两倍左右。** 想让它走得稳，务必做这四件事：

1. **舵机用 6V 而不是 5V** —— 扭矩从 1.8 提到 2.2+ kg·cm，白赚 20~30%，这是最划算的一招（MG90S 标称 4.8~6.0V）
2. **触手控制在 9cm 以内**，理想 7~8cm
3. **结构件打薄**：PLA 填充率 15~20% 足够，别打实心
4. **重心压低**：重的东西尽量装在底部

### 想做小 / 想做大

- **想更小 → 把开发板外置**。用 20~30cm 杜邦线把主控板放在体外，躯干能缩到 6cm 直径，展开约 20cm，还少 60g。代价是拖一根线，不能全无线。
- **想更大 → 必须换舵机**。MG90S 撑不住 12cm 以上的触手。换成 MG996R（55g，扭矩 11~13 kg·cm），光舵机就 880g，电源要 10A 以上，成本和体积都翻倍。**建议先按现在的尺寸做出来，跑稳了再考虑放大。**
