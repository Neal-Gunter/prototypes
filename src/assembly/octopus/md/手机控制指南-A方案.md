# 手机控制指南 · 方案 A（手动蓝牙，零代码）

> 配合 `body_firmware_A.ino` 使用。手机**不需要写任何代码**，装一个蓝牙串口 App 发文字指令就行。

---

## 1. 你要准备的东西

| 东西 | 说明 |
|---|---|
| 已烧好 `body_firmware_A.ino` 的身体（ESP32-S3 + PCA9685 + 舵机 + 电池） | 见下面第 2 步确认上电正常 |
| 安卓手机（你已有的） | iOS 也可以，但安卓 App 更通用 |
| 蓝牙串口 App | **强烈推荐 [Serial Bluetooth Terminal](https://play.google.com/store/apps/details?id=de.kai_morich.serial_bluetooth_terminal)**（免费，支持经典蓝牙 SPP，正好对上身体固件） |
| （可选）小智安卓客户端 | 单纯用来和八爪鱼"聊天陪伴"，和动作控制是两套独立 App，互不影响 |

> 备选 App：应用商店搜「蓝牙串口」也能找到一堆；只要支持 **SPP（经典蓝牙串口）** 就行。Serial Bluetooth Terminal 是最稳的。

---

## 2. 身体上电后先确认它"活着"

1. 给身体通电（插电池或 USB 给 ESP32 供电，舵机走 PCA9685 的 V+）。
2. 用一根 USB 线把 ESP32 连电脑，打开 Arduino 串口监视器（波特率 115200）。
3. 你应该看到打印：
   ```
   PCA9685 #0 (0x40) 就绪
   Octopus body ready. BT name = OctoBrain
   ```
   如果卡在 "PCA9685 初始化失败"，先回去查 SDA/SCL 接线、PCA9685 供电、地址（默认 0x40）。
4. 此时舵机会**分时**慢慢回到中位（约 1~2 秒），这是 `SoftHome()` 在干活，正常现象。

---

## 3. 手机配对 + 连接（三步）

1. 手机系统设置 → 蓝牙 → 打开，搜到名为 **`OctoBrain`** 的设备 → 配对（多数情况下无 PIN，或输 `1234`）。
2. 打开 **Serial Bluetooth Terminal**。
3. 点左上角菜单 → **Devices** → 选 `OctoBrain` → 连接。顶部状态变成 `Connected` 就成功了。

> 第一次连不上：先删掉系统蓝牙里已配对记录重连一次；确认身体通电且名字是 OctoBrain。

---

## 4. 发指令让它动（核心）

在 App 底部的输入框打字，每条指令结尾**必须换行发送**（点输入框旁边的发送键，或键盘回车）。指令不区分大小写。

| 你发 | 八爪鱼做什么 |
|---|---|
| `WALK` 或 `GO` | 开始爬行（相对自身向前） |
| `LEFT` | 向左转（差速） |
| `RIGHT` | 向右转 |
| `STOP` 或 `REST` | 停，回到待机中位 |
| `WAVE 3` | 第 3 号触手挥一下（编号 0~7，从正前方顺时针） |
| `PULSE 3` | 八条同步缩成一团 3 次（"害怕"表情） |
| `HOME` | 强制回中位 |
| `GAIT f=0.6 yaw=38 lift=20 phase=45 duty=0.65` | **现场调步态参数**，不发这条就用默认 |

每发一条，手机会回显 `> WALK` 表示收到了。

---

## 5. 调出"像章鱼"的手感（不用重新烧录）

在 `WALK` 状态下，用 `GAIT ...` 实时改参数感受差别：

| 参数 | 作用 | 建议范围 |
|---|---|---|
| `f` 步频 | 动得多快 | 0.3 慢而稳，1.0 以上舵机开始跟不上 |
| `yaw` 摆幅 | 触手前后扫的幅度 | 30~45 |
| `lift` 抬幅 | 触手抬起高度 | 15~30 |
| `phase` 相位差 | **最关键的"章鱼感"** | `0`=8 条同步脉冲；`45`=环形波（最像爬行）；`180`=左右交替 |
| `duty` 占空比 | 慢推快收的比例 | 0.5~0.7，大于 0.5 才像"慢慢撑地推进、快速收回" |

**经验起点**：`GAIT f=0.6 yaw=38 lift=20 phase=45 duty=0.65`
想看"八条像波浪一样依次动"就把 `phase` 调到 45；想看"八条一起蹦"就设 `phase=0`。

---

## 6. 两个安全习惯

- **动完就发 `STOP`**：身体有 15 秒无指令自动待机，但手动发 `STOP` 更稳，也省电。
- **电池版务必看电量**：如果舵机开始抖、板子反复重启，先 `STOP` 再充电。启用低压保护（在固件里取消 `#define BATTERY_PIN` 注释并接好分压）后，低于 6.4V 会自动停。

---

## 7. 它和"聊天"是分开的（方案 A 的边界）

现在身体**只听蓝牙指令**，不听你说话。你手机上：
- **Serial Bluetooth Terminal** = 控制身体（手动发 WALK/LEFT…）
- **小智安卓客户端** = 和八爪鱼语音聊天（纯陪伴，暂时不联动动作）

等你玩顺了，想"说一句它就动"，再升级到方案 B/C（把对话结果自动转成蓝牙指令发给身体），那份代码我们另外给。

---

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 手机搜不到 OctoBrain | 身体没通电 / 蓝牙没开；确认 `SerialBT.begin("OctoBrain")` 已烧入 |
| App 连上但发指令没反应 | 指令没换行发送；或舵机/PCA9685 没供电（看第 2 步串口日志） |
| 连上后乱码 | 波特率无关（蓝牙是数字链路），通常是发了非 ASCII；只用英文指令 |
| 一动就重启 | 电池/电源带不动 16 舵机 → 用更大电流电源，或先只接 4 个舵机验证 |
| 想用 iOS | 换支持 BLE UART 的 App（如 nRF Connect 写 Nordic UART 服务）；本固件默认是经典蓝牙 SPP，iOS 支持差一点 |
